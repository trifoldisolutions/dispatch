# new_project_sample

This is what a new project starts with: `AGENTS.md` and `dev_resources/init_prompt.md`, with `:projectFolderName` standing in for the project's folder name.

Don't copy this folder. New projects start from Dispatch, which fills in the name and lists the project: see `AGENTS.md` in the folder above.

Dispatch rewrites this folder from `dispatch/config/project_template/` each time it starts, so edit the standard there. Changes made here are lost.
